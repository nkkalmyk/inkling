# Проверка Inkling перед коммитом и PR

Правила и команды живут в `AGENTS.md` (разделы «Команды», «Правила работы с репозиторием»). Здесь только порядок шагов; при расхождении верь `AGENTS.md`.

Живые тесты (`TEST_RUNNER_INKLING_LIVE_*`) в проверку не входят: без просьбы владельца не запускай.

## 1. Сборка и тесты

```bash
xcodegen generate && xcodebuild -scheme Inkling -destination 'platform=macOS' build test 2>&1 | tee "$TMPDIR/inkling-check.log" | tail -40
grep -E 'warning:|error:' "$TMPDIR/inkling-check.log" | sort -u | head -40
```

Долгая команда (1–2 мин): запускай в фоне. Нужны: `** TEST SUCCEEDED **`, ноль `warning:` из кода проекта.

Если сломано — чини по одной ошибке: прочитай место ошибки, исправь, пересобери. Новая ошибка после правки или та же ошибка после трёх попыток — остановись и опиши владельцу, что видишь.

## 2. Статический анализ

```bash
xcodebuild -scheme Inkling -destination 'platform=macOS' analyze 2>&1 | grep -E 'warning:|error:|ANALYZE' | sort -u | tail -20
```

## 3. Секреты

```bash
gitleaks dir . --redact
```

Должно быть `no leaks found`. Нашлось — сообщи владельцу, ничего не «заметай».

## 4. Индекс и рабочее дерево

```bash
git status --short && git diff --staged --stat
```

- В индексе только файлы этой задачи. Чужие незакоммиченные файлы (см. память о состоянии репозитория) не подмешивай.
- Никакого личного: `Config/Signing.xcconfig`, `TestData/real/`, `docs/LITERATURE.local.md`, `docs/cli-experiments/tmp/`, `*.xcodeproj/`, `build/`, временные стенды вроде `InklingTests/ScreenHarnessScratch.swift`.
- Ветка не `main`.

## 5. Дифф против правил

Пройди `git diff main...HEAD` и `git diff` и проверь:

- Поведение изменилось — есть тест.
- Видимое пользователю — строка в `CHANGELOG.md`; остальные доки — по таблице «Документация идёт вместе с кодом».
- Интерфейс — по `docs/design-system.md`, экран посмотрен в запущенном приложении (сборки мало).
- Не тронуты без вопроса промпты `Inkling/Resources/Prompts/`, решения `SPEC.md` §13, изоляция `claude` в `ClaudeCodeEngine`, `vendor/`, bundle id.
- Нет личной почты и домашних путей в коде, коммитах, описании PR.

## Отчёт

```
ПРОВЕРКА INKLING
Сборка и тесты: ОК / СЛОМАНО (N тестов, предупреждений: N)
Анализ:         ОК / N замечаний
gitleaks:       ОК / НАЙДЕНО
Индекс:         ОК / лишнее: …
Правила:        ОК / не хватает: …
Итог:           ГОТОВО к коммиту/PR / НЕ ГОТОВО
Не проверено:   …
```

Раздел «Не проверено» не пропускай: его содержимое идёт в описание PR.
