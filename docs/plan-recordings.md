# План: аудио и видео в конспект

Статус: план, кода нет. Решения собраны в опросе 2026-10-19; когда план утвердят, они переедут в `SPEC.md`, раздел 13.

## Что делаем

Лекцию можно записать (диктофон, запись экрана, видео) и добавить файл в приложение. Приложение достаёт звук, расшифровывает его локальным Whisper, Claude или Codex превращают сырую речь в аккуратный текст, а сборка использует этот текст как ещё один источник рядом с тетрадью и слайдами.

```
файл (аудио/видео) ──► звук m4a ──► whisper.cpp ──► сырой текст [мм:сс] ──► очистка Claude/Codex ──► текст записи ──► сборка konspekt.md
   (с диска)           (AVFoundation)   (на устройстве)                         (по кускам)         (можно править)     (с выбором главного)
```

## Решения (из опроса)

| Вопрос | Решение |
|---|---|
| Источник | Только файлы с диска: перетаскивание, «Добавить файлы…», диктофон, запись экрана. Ссылки (YouTube и т. п.) не делаем: это сеть, внешний загрузчик и условия сервисов. Архитектуру не закрываем, но в этот план ссылки не входят |
| Видео | Только звук. Кадры слайдов и доски (ключевые кадры в распознавание слайдов) — отдельный следующий этап |
| Речь → текст | Только Whisper через CLI `whisper-cli` из `whisper.cpp` (`brew install whisper.cpp`). Встроенный Apple Speech не используем: для русского у `SpeechTranscriber` нет модели (проверено на этом Mac), остаётся старая диктовка худшего качества |
| Модель Whisper | Пользователь скачивает сам и указывает путь в настройках; у приложения по-прежнему нет сетевых вызовов. В настройках — инструкция |
| Хранение | В папке лекции только сжатый звук (моно AAC ≈ 32 кбит/с, около 20 МБ за 90 минут). Исходное видео не копируется: iCloud и размер папки |
| Структура | Третий раздел «Записи» во вкладке «Источники», рядом с «Мой конспект» и «Слайды». В `meta.json` новый массив `recordings`, остальное не меняется |
| Время | В сыром тексте метки `[мм:сс]` примерно каждые 30–60 с; в очищенный текст они не попадают |
| Очистка | Отдельный шаг: сырой текст режется по меткам на куски, Claude или Codex убирают паразитов и повторы, оставляют термины. Результат — текст записи, его можно править |
| Формулы из речи | «икс в квадрате плюс единица» → `[?$x^2+1$]` с пометкой догадки (точки под формулой); тетрадь и слайды могут подтвердить и снять скобки |
| Сборка | Если источников больше одного, перед сборкой спрашиваем, что главное: тетрадь, запись или слайды. Без тетради конспект собирается из записи |
| Облако | Очистка и сборка идут через облачный движок (`AIRequest.cloudOnly`), локальная Ollama для них не годится |

Для остального приняты такие решения, их можно оспорить:
- Язык расшифровки — настройка, по умолчанию русский (`-l ru`); «авто» доступно.
- В Whisper передаётся подсказка (`--prompt`) с предметом и темой лекции, чтобы он узнавал термины.
- Живой записи с микрофона внутри приложения нет: берём готовые файлы.

## Этапы

Работаем по порядку: следующий этап не начинаем, пока предыдущий не собирается, тесты не зелёные и приложение не запускается.

### Этап 0. Разведка whisper.cpp
- `brew install whisper.cpp`, `whisper-cli --help`, проверка разбора аргументов; тестовая модель (tiny, ~75 МБ) только для разведки.
- Звук для проверки: `say -v Milena` (русский) → m4a; лекция с терминами и формулами «вслух».
- Выяснить и записать в `docs/cli-notes.md`: формат входа (WAV 16 кГц моно?), вывод (`-oj` JSON с сегментами и временем, `-ml`, `-nt`), прогресс (`-pp`), потоки и Metal, `--prompt`, `-l ru`, поведение при отсутствии модели, при пустой тишине, при слишком большом файле, коды выхода и тексты ошибок.
- Выход: заметки в `cli-notes.md`, сырые выводы в `docs/cli-experiments/raw/` (без личных данных).
- Для установки нужно разрешение на `brew install` (скачивание).

### Этап 1. Модель данных и импорт
- `RecordingItem` в `meta.json`: `id`, имя источника, длительность, дата добавления, статус, описание текста (по образцу `PageText`: движок, модель, правка вручную, хеш звука). Старые `meta.json` читаются без изменений.
- Папка: `recordings/audio/<id>.m4a`, `recordings/pages/<id>.md` (сырой текст с метками), `recordings/clean/<id>.md` (очищенный), история версий через `HistoryStore`.
- Импорт: типы аудио и видео в `ImportStaging`/`SourceImporter`, перетаскивание и «Добавить файлы…». `AVAssetExportSession`/`AVAssetReader` достаёт звуковую дорожку в m4a и во временный WAV для Whisper.
- Ограничения: длительность до 6 часов, размер входа (аналог лимитов BUG-06), понятная ошибка для файла без звука и с защитой DRM.
- Тесты на синтетике (`say`), без реального видео в репозитории.

### Этап 2. Расшифровка
- Протокол `TranscriptionEngine` (по образцу `AIEngine`) и `WhisperCLIEngine`: поиск `whisper-cli` через `BinaryLocator`, ручной путь, `ProcessRunner`, отмена, таймаут по длительности записи.
- Очередь `RecordingCenter` (по образцу `RecognitionCenter`): прогресс (минуты из общих), отмена, ошибки (нет бинарника, нет модели, не хватило памяти), блокирующие ошибки останавливают очередь.
- Разбор вывода в строки `[мм:сс] текст`; вычистка галлюцинаций на тишине (повторы одной фразы, «Субтитры сделал…»).
- Настройки: путь к `whisper-cli`, путь к модели (с поиском в типичных местах), язык, потоки; «Проверить подключение» (версия, модель на месте, расшифровка короткого тестового звука).
- Тесты: разбор на синтетических и настоящих выводах; живой тест по флагу.

### Этап 3. Очистка текста
- Промпт `clean-recording.md` (+ вставка предмета): убрать «э-э», повторы и оговорки, сохранить термины и числа, ничего не придумывать, разбить на абзацы; формулы из речи оформить `[?$…$]`.
- Резка сырого текста на куски ~12 000 символов по меткам времени с перекрытием в несколько фраз; куски идут параллельно (как части сборки), результат склеивается.
- Проверки кодом: длина очищенного текста в разумных пределах относительно сырого (защита от «поджатия» лекции до пары абзацев и от выдумок), наличие всех кусков.
- Только облачные движки. История версий, ручная правка, сброс.
- Живой тест на синтетической «лекции» через Claude.

### Этап 4. Сборка
- Режимы сборки добавляются к существующим (тетрадь / тетрадь + слайды / только слайды): появляются «запись», «тетрадь + запись», «все три».
- Перед сборкой при двух и более источниках диалог «Что главное?». Выбор запоминается для лекции.
- Промпты `assemble-recording*.md`: тетрадь главная — текст автора неприкосновенен, запись заменяет `[неразборчиво]` и догадки, добавляет блоки `🎙️ Из записи`; запись главная — каркас из речи, тетрадь уточняет формулы и обозначения.
- `AssemblyPlanner`: размер записи в длине входа, нарезка на части для длинных лекций, пропорциональный срез записи по частям (как у слайдов).
- «Устарело» учитывает записи (хеш очищенного текста и порядок). Учебные материалы и «Дополнить» не ломаются: блоки `🎙️` — часть текста конспекта, считаются как `📎`.
- Рендер: стиль блока `🎙️ Из записи` в `render.js` и `notes.css`.

### Этап 5. Интерфейс
- Раздел «Записи» в «Источниках»: список записей со статусом (очередь, расшифровка с прогрессом, очистка, готово, ошибка), длительностью и размером звука.
- Страница записи: текст с метками времени, переключатель «Сырой / Очищенный», правка, «Расшифровать заново», «Очистить заново», «История», кнопка «Открыть звук».
- Пустое состояние с инструкцией: поставить `whisper.cpp`, скачать модель, указать путь. Ссылка на настройки.
- Настройки: блок «Расшифровка записей» на вкладке «Движок».
- Всё на дизайн-системе `Inkling/DesignSystem/`, по чек-листу `docs/design-system.md`.

### Этап 6. Завершение
- Документация: `SPEC.md` (раздел 13), `README.md`, `docs/INSTALL.md` (установка whisper.cpp и модели), `docs/cli-notes.md`, `CHANGELOG.md`.
- Сквозной прогон на синтетической лекции (аудио → конспект) и на одной реальной записи пользователя; результаты в `docs/e2e-report.md`.
- Версия 0.5.0.

## Риски

| Риск | Что делаем |
|---|---|
| Качество русского на терминах и формулах | Модель large-v3-turbo, `--prompt` с предметом и темой, формулы только как помеченные догадки, правка вручную |
| Длительность расшифровки (90 минут на слабом Mac) | Фоновая очередь, прогресс, отмена; в инструкции совет по размеру модели (small/medium/turbo) |
| Галлюцинации Whisper на тишине и музыке | Чистка повторов, опция пропуска тишины, проверка кодом |
| Лимит Claude: 90 минут речи — 6–8 вызовов очистки плюс сборка | Показ оценки вызовов перед запуском; очистка по кнопке, а не молча |
| Размер папки и iCloud | В папке лекции только m4a ~32 кбит/с; видео не копируется |
| Приватность записи | Звук не покидает компьютер; в облачный движок уходит только текст. В README напомнить, что запись лекции требует разрешения лектора |
| Нет `whisper-cli` или модели у пользователя | Ясные ошибки и инструкция; остальное приложение работает как раньше |
| Whisper ломается на новой версии macOS или whisper.cpp | Версия фиксируется в `cli-notes.md`, разбор вывода покрыт тестами на сохранённых образцах |

## Что вне плана

Ссылки на видео и стриминговые плееры; кадры слайдов и доски; запись с микрофона внутри приложения; разделение по говорящим; субтитры из видео; Whisper через API OpenAI (в приложении нет ключей и сети).

## Вопросы, которые остаются

1. Какую модель Whisper рекомендовать по умолчанию в инструкции: `large-v3-turbo` (~1,6 ГБ, лучше) или `small` (~0,5 ГБ, быстрее и легче)? Решится на этапе 0 замером на этом Mac.
2. Нужен ли отдельный экран прогресса расшифровки или хватит строки в списке записей?
3. Сколько записей в одной лекции разрешать (лекция из двух частей, запись семинара)? Предлагаю без ограничения, по порядку добавления.
