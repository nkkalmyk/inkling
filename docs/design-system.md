# Дизайн-система Inkling

Как выглядит и ведёт себя интерфейс и что брать при добавлении нового экрана. Код лежит
в `Inkling/DesignSystem/`: `Tokens/` (значения) и `Components/` (общие виды). У каждого
компонента есть `#Preview` в светлой и тёмной теме (`ThemePair`). Решения согласованы
в SPEC, раздел 13 («Дизайн-система»).

## Принципы

- **Нативно прежде всего.** Системные контролы, стили кнопок, `List`, `Form`, `ContentUnavailableView`.
  Своё — только там, где системы нет (вариант ответа, кольцо результата, флеш-карточка).
- **Две зоны.** «Источники» и «Конспект» — строгий рабочий инструмент. «Самопроверка»
  (вопросы, тест, карточки) — тёплая зона: символы в акценте, сдержанные анимации-награды. Фон у неё
  системный, как у всего окна: своего цвета фона нет.
- **Цвет только по делу.** Акцент — действия и выделение. Красный — ошибка, зелёный — успех.
  Предупреждения и сведения («устарело», «в очереди») бесцветные: значок и слова.
  Исключение — пометка «Сделано локальной моделью — проверьте»: выделена формой (`ReviewBadge`).
- **Ничего только цветом.** У статуса всегда есть значок и подпись (подсказка и VoiceOver).
- **Работа — в тулбаре, сообщения — в шапке.** Идущая работа видна в индикаторе активности,
  ошибки и «устарело» — уведомлением `InlineNotice` над содержимым. Цветных полос нет.
- **Минимум macOS 26.** Liquid Glass только системный (тулбар, сайдбар, контролы), своего `glassEffect` нет.

## Токены

### Цвет (`Tokens/Colors.swift`, `Assets.xcassets`)

| Токен | Где | Значение |
| --- | --- | --- |
| `Color.accentColor` | действия, выделение, символы зоны самопроверки | янтарь капли из иконки: `#9A5F00` светлая, `#F5B83D` тёмная (+ варианты высокого контраста) |
| `.onAccent` | подпись на акцентной заливке | белый / почти чёрный (на светлом янтаре тёмной темы) |
| `.surfaceRaised` | карточка на фоне окна | `quaternarySystemFill` |
| `.surfaceSunken` | подложка под картинками | `quinarySystemFill` |
| `.surfaceStudy` / `.surfaceStudyRaised` | фон и карточки самопроверки | `windowBackgroundColor` / `quaternarySystemFill` |
| `.statusError` / `.statusSuccess` | ошибка / успех | системные красный и зелёный |
| `.statusNeutral` | сведения и предупреждения | `.secondary` |
| `.selectionNeutral` | выбранный сегмент переключателя разделов | `unemphasizedSelectedContentBackgroundColor` |
| `NSColor.appAccent` | тот же акцент в AppKit-видах: пометки `[неразборчиво]` и `[?догадка]` в редакторе страницы | `AccentColor` |

Текст — системные `.primary`, `.secondary`, `.tertiary`. Шестнадцатеричных цветов в экранах нет.

Акцент приложения macOS показывает, когда в Системных настройках выбран акцент «Разноцветный»;
при другом системном акценте контролы берут его — это поведение системы.

### Шрифты (`Tokens/Typography.swift`)

Интерфейс — SF (системные `.body`, `.callout`, `.caption`, `.headline`). Тексты для чтения — New York.

| Токен | Где |
| --- | --- |
| `.screenTitle` | заголовок листа, крупного состояния |
| `.sectionTitle` | заголовок раздела в экране |
| `.meta` | служебные строки, шапки вкладок |
| `.label` | подпись над содержимым («Ответ») |
| `.mono` | технические подробности, исходный текст версии |
| `.readingFont()` / `.readingFont(large: true)` | вопросы, ответы, карточки (New York): кегль стиля `title3` / `title2` × масштаб «Вид → Крупнее/Мельче» |
| `.metric` | счёт теста и карточек |
| `.illustration` | крупный символ начального экрана |

Пометки распознавания одинаковы в редакторе и в конспекте: `[неразборчиво]` — янтарная подложка,
догадка модели `[?слово]` — янтарное подчёркивание точками.

На macOS нет системного Dynamic Type: `dynamicTypeSize` шрифты не меняет (проверено на macOS 26), а `.body` не следует
настройке размера текста в Универсальном доступе. Поэтому размер текста для чтения задаёт сам пользователь:
«Вид → Крупнее / Мельче / Обычный размер» (⌘+ или ⌘=, ⌘−, ⌘0), значение `ReadingScale` в `UserDefaults`,
в окружении — `\.readingScale`. Конспект масштабируется целиком (`pageZoom`). Интерфейсный текст остаётся системным.

Веб-фрагменты с формулами (`Resources/Web/snippet.html`) набираются тем же кеглем, конспект
(`notes.css`) — New York 17 px. CSS-переменные `notes.css` повторяют цветовые токены: при их
изменении правьте оба места.

### Отступы, радиусы, ширины (`Tokens/Layout.swift`)

- `Spacing`: `xxs` 2 · `xs` 4 · `s` 8 · `m` 12 · `l` 16 · `xl` 20 · `xxl` 24 · `xxxl` 32. Других чисел в отступах нет.
- `Radius`: `chip` 4 · `control` 8 · `card` 12; фигура — `RoundedRectangle.ds(_:)` (непрерывное скругление).
- `SheetWidth`: `compact` 400 · `regular` 480 · `wide` 620. `ReadingWidth`: `focused` 720 · `column` 820.

### Движение (`Tokens/Motion.swift`)

Пружины без отскока: прерываемые, продолжают с текущей скорости.

| `Motion` | Где |
| --- | --- |
| `.standard` (0,35 с) | смена состояний, уведомления, раскрытие ответа |
| `.snappy` (0,2 с) | нажатие, выбор варианта |
| `.card` (0,45 с) | переворот и уход флеш-карточки, кольцо результата |

`.motion(_:value:)` вместо `.animation`, `withMotion(_:reduceMotion:)` вместо `withAnimation`:
при «Уменьшить движение» оба дают короткое растворение. Переходы появления уведомлений —
`.transition(.notice(reduceMotion:))`.

## Компоненты

| Компонент | Зачем |
| --- | --- |
| `InlineNotice(.info / .attention / .error, …)` | сообщение в шапке экрана, с действиями, «Подробности» и закрытием |
| `ActivityIndicator` + `Activity` | идущая работа в тулбаре: только кружок прогресса (без подписи, иначе тулбар переполняется); по щелчку — названия, время, «Отменить» |
| `ElapsedText` | «3:07» с начала работы |
| `prominentAction()` | главное действие экрана (акцентная кнопка с правильной подписью) |
| `IconButton` | кнопка-значок с обязательным названием |
| `Chip` (`.neutral`, `.accent`, `.error`, `.overlay`) | короткая метка; `.overlay` — поверх картинки |
| `StatusSymbol` | значок состояния с подписью |
| `.surface(_:radius:)` | подложка тоном, без рамки и тени |
| `EmptyState` | пустой экран (обёртка `ContentUnavailableView`) |
| `FormSheet` | лист с формой: заголовок, поля, Esc/Return; закрывается, если `confirm` вернул `true` |
| `HistoryPopover` | история версий с предпросмотром и «Восстановить» |
| `.sectionSwitcher(.primary / .inline)` | переключатель разделов и режимов: капсула и нейтральный выбранный сегмент, как в тулбаре; `.primary` — под тулбаром, `.inline` — в строке экрана. Переключатели значений в формах — системные |
| `ResizableSplit` | две колонки с перетаскиваемой границей там, где они начинаются у верха окна (`HSplitView` в macOS 26 продлевает разделитель в тулбар) |
| `QuizOptionStyle` | вариант ответа (верно/неверно значком) |
| `ScoreRing` | итог теста и карточек |

Даты: `Date.stamp` («14 окт., 15:30»), `Date.preciseStamp` (с секундами), `CalendarDate.formatted`.
Локаль задана в `UIFormat` — не передавайте `Locale` вручную.

## Каркас лекции

- Окно — три колонки `NavigationSplitView`, как Заметки и Bear: сайдбар («Все лекции», предметы со счётчиками,
  «Новый предмет» внизу) → список лекций (`LectureListView`: тема, дата, число страниц, тихий статус; поиск
  `.searchable` по теме и предмету из `meta` в памяти, ⌘F) → лекция. Заголовок окна — у списка («Все лекции»,
  «Лекций: 4»), тема открытой лекции видна выделенной строкой.

- Тулбар: переключатель «Источники · Конспект · Самопроверка» (`LectureZoneItem`), индикатор активности
  (импорт, распознавание, сборка, подготовка материалов, экспорт PDF — всё здесь, не в шапке экрана),
  главная кнопка следующего шага (`LecturePrimaryAction`: Распознать → Собрать конспект → Подготовить материалы),
  меню модели, «…» (экспорт, изменить, Finder).
- Строка меню: «Файл → Новая лекция» ⌘T (и ⌘N), «Лекция» (следующий шаг ⌘↩, «Повторить карточки» ⌘R, экспорт, изменить ⌘I,
  Finder ⇧⌘R), «Правка → Найти лекцию» ⌘F, в «Вид» размер текста ⌘+ ⌘− ⌘0, разделы ⌘1–⌘5 и
  «Правка конспекта» ⇧⌘E. Команды получают действия через `FocusedValues.lectureCommands`.
- Повторение карточек — слой на всё окно (`FlashcardReviewView` поверх колонок, тулбар скрыт
  `toolbarVisibility(.hidden, for: .windowToolbar)`): одна карточка, «Готово» или Esc — выход. Владелец сеанса —
  `Library.review`; вкладка «Карточки» только запускает его. Скрыть колонки `columnVisibility: .detailOnly` нельзя:
  на macOS 26 трёхколоночный `NavigationSplitView` его не выполняет (проверено).
- Шапка экрана — только действия над его содержимым, одинаковыми кнопками: «Пересобрать», «История»
  у конспекта; «Распознать заново» (в меню кнопки — «Распознать подробно») и «История» у страницы.
  Вариант действия — в меню кнопки (`Menu` с `primaryAction`), а не отдельной кнопкой рядом.
- Действие, которое уже предлагает уведомление в шапке («Устарело» → «Пересобрать»), в строке экрана не повторяется.
- Поля: строка экрана — `m` по горизонтали и `s` по вертикали; содержимое экрана — `xxl`; карточка — `l`.
  Каждая вкладка заполняет всю область (корень `KeptAliveTabs` растянут), пустое состояние — тоже.
- Действие с подтверждениями экрана (сборка, дополнение, подготовка) тулбар запрашивает флагом `LectureRequests`
  в окружении; экран забирает флаг в `task(id:)`.

## Новый экран: чек-лист

1. Отступы, радиусы, шрифты, цвета — только токены. Нет `.orange`, `.yellow`, чисел в `padding`.
2. Пустое состояние — `EmptyState`; ошибка и «устарело» — `InlineNotice` в шапке; прогресс — `Activity`
   в `LectureActivityIndicator`, а не полоса в экране.
3. Главная кнопка — `prominentAction()`, одна на экран. Значки-кнопки — `IconButton`.
4. Списки с выбором — `List(selection:)` (стрелки, ⇧/⌘, Delete), не `onTapGesture`. Список `.sidebar`
   вне настоящего сайдбара — с `.scrollContentBackground(.hidden)`: материал сайдбара уходит под тулбар.
5. Каждое действие экрана доступно с клавиатуры или из строки меню.
6. Анимации — через `Motion`; проверьте «Уменьшить движение».
7. Компонент дизайн-системы — с `#Preview` в `ThemePair`.
   В `body` нет чтения файлов: библиотека лежит в iCloud Drive, файл может быть выгружен, и чтение на главном
   потоке ждёт загрузки. Сводки — `knownReadiness`/`knownStale`, содержимое — `.task(id:)` с `@concurrent`-чтением.
8. Самопроверка — на `.surfaceStudy` (системный фон окна), символы `tint: .accentColor`. Над вкладками —
   одна полоса `StudyModeBar`: источник материалов, режим, «Подготовить заново»; своих строк вкладки не добавляют.

## Экспорт

- PDF сохраняется сразу в «Документы → Конспекты» (`Тема — Предмет — ГГГГ-ММ-ДД.pdf`) и показывается в Finder.
- Блоки, добавленные прежней функцией «Дополнить» (`💡`, `📝`, `🔗`), — та же вставка, что и прочие: нейтральная подложка и акцентная граница,
  различает их значок; резюме `🧭 Главное` — список в такой же вставке. Графики и схемы берут цвета из переменных `notes.css`.
- PDF (`Export/PDFExporter.swift`): печать `notes.html` со стилями `@media print` из `notes.css`,
  титул `PrintHeading`, колонтитулы `PDFFooter`. Печатается всегда светлая тема.
- Markdown (`Export/MarkdownExporter.swift`): YAML-шапка и заголовок лекции; текст конспекта не переписывается.
