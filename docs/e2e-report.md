# Сквозной прогон (SPEC, раздел 10)

Дата: 2026-10-14. Mac M5, macOS 27.0.1, Xcode 27.0, Claude Code 2.1.289, модель `claude-sonnet-5-5` (алиас `sonnet`).
Тест: `InklingTests/EndToEndTests.swift` (живой, по флагу `TEST_RUNNER_INKLING_LIVE_CLAUDE=1`).

## Данные

- `TestData/synthetic/chem-page.png` — «рукописная» страница по ОВР (шрифт Bradley Hand на линованной бумаге).
- `TestData/synthetic/slides.pdf` — 3 слайда с текстовым слоем: титульный, «Основные понятия», «Спасибо за внимание!».
- `TestData/real/` — **пусто**: реальных фото на момент прогона не было. Прогон нужно повторить, когда они появятся (тест подхватит их сам).

Дополнительно отдельными живыми тестами проверено:
- распознавание JPEG-страницы по матанализу (пределы, производная, интеграл, ряд — верный LaTeX);
- сборка с намеренной ошибкой в рукописи («степень окисления O в H₂O равна +2») — модель отметила `> ⚠️ Возможно, ошибка`;
- отмена идущего вызова — процессы и временные папки не остаются; неверная модель и отсутствие входа дают понятные ошибки.

## Замеченные проблемы и что сделано

1. **PDF без формул.** Первая версия экспорта печатала конспект до загрузки шрифтов KaTeX: в PDF были видны только стрелки. `document.fonts.ready` срабатывает раньше, чем WebKit начинает грузить шрифты. Исправлено: шрифты KaTeX грузятся явно, сигнал «отрисовано» уходит после них.
2. **Зависание печати.** Синхронный `NSPrintOperation.run()` для WKWebView бесконечно перерисовывал страницы. Исправлено: асинхронный `runModal(for:)`; делегат вызывается в фоновом потоке и не привязан к главному актору.
3. **Извлечение текста из PDF.** PDFKit отдаёт кириллическую «к» системного шрифта как «ĸ». На вид PDF правильный; влияет только на поиск по тексту PDF. Не исправлялось.
4. **Служебные слайды.** «Спасибо за внимание!» ушёл в распознавание картинкой (текста мало). Модель ничего из него в конспект не взяла, но вызов потрачен. Можно заранее снимать такие слайды флажком «Не включать в конспект».
5. **Синтетика не заменяет рукопись.** Автообрезка и распознавание настоящего почерка на этих данных не проверены — нужен прогон с `TestData/real/`.

## Как повторить

```
TEST_RUNNER_INKLING_LIVE_CLAUDE=1 TEST_RUNNER_INKLING_E2E_OUT=/tmp/inkling-e2e \
  xcodebuild -scheme Inkling -destination 'platform=macOS' test -only-testing:InklingTests/EndToEndTests
```
В `/tmp/inkling-e2e` будут тексты страниц, `konspekt.md`, `konspekt.pdf`, `study.json`, `anki.csv` и `log.txt`.
