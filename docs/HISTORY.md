## День 1 — 14 октября: от ТЗ до работающего конвейера

Работа шла строго по этапам из `SPEC.md`, раздел 11: следующий этап начинался только после зелёной сборки и тестов.

- **ТЗ и правила проекта.** Нативное macOS-приложение (Swift 6, SwiftUI, XcodeGen). Своих API-ключей нет:
  приложение запускает уже установленные консольные ИИ-утилиты. Все данные лежат обычными файлами в `~/Documents/Inkling/`.
- **Этап 0: разведка CLI.** До кода выяснили, как реально ведут себя `claude` и `gemini` в headless-режиме
  (флаги, формат ответа, ошибки лимита, изоляция от глобальных настроек). Всё записано в [`cli-notes.md`](cli-notes.md),
  сырые выводы лежат в `docs/cli-experiments/`.
  - **Главное решение:** основным движком стал Claude Code, а не Gemini CLI. Gemini CLI с 18.06.2026 не обслуживает
    подписки Google AI Pro, его замена Antigravity CLI отказала аккаунту по стране. Подробности — [PROBLEMS.md](PROBLEMS.md#движки).
- **Этапы 1–2.** Скелет приложения, импорт и предобработка: перетаскивание, вставка, PDF, автообрезка и выпрямление листа
  (Vision + Core Image), HEIC → JPEG, текст слайдов из текстового слоя PDF.
- **Этап 3: движок Claude Code.** `ProcessRunner` на `posix_spawn`, изоляция вызова (отдельная временная папка,
  только инструмент `Read`, без MCP, хуков и пользовательских настроек), распознавание лимитов и ошибок.
- **Этапы 4–6.** Распознавание страниц в Markdown + LaTeX + `\ce{}`; сборка конспекта без дублей на стыках; рендер
  через встроенные KaTeX, mhchem, markdown-it; учебные материалы (резюме, термины, вопросы, тест, карточки).
- **Этап 7.** Экспорт (Markdown, PDF A4, CSV для Anki), итоговая иконка в формате Icon Composer, подпись Personal Team,
  сквозной прогон ([`e2e-report.md`](e2e-report.md)): короткая лекция целиком за ~34 с.
- **Этап 8: запасной движок Ollama.** После сравнения локальных моделей ([`local-models.md`](local-models.md)) выбрана
  Qwen3.5-9B с настройками под распознавание (`inkling-ocr`). Ручной выбор модели и режимов «Авто / Только Claude / Только локальная».

## День 2 — 15 октября: дизайн, аудит, «Дополнить»

- **Дизайн-система** (PR #1, версии 0.2.0–0.2.1). Токены и компоненты, янтарный акцент из иконки, минимум macOS 26
  (Liquid Glass без `if #available`), плавное переключение вкладок, красивый экспорт. Правила — [`design-system.md`](design-system.md).
- **Камера непрерывности** (0.2.2–0.2.3). Импорт снимка или скана прямо с iPhone; пара итераций, пока не заработало.
- **README как страница проекта.** Логотип, бейджи, схема конвейера на Mermaid.
- **Аудит безопасности и надёжности** (PR #3, [`AUDIT.md`](AUDIT.md)). Нашли и исправили выход за пределы папки лекции
  через `meta.json` (SEC-01), удалённые картинки в конспекте (SEC-02), падение на дубликатах `id` в `study.json` (BUG-01)
  и ещё ряд замечаний. Остатки — в [PROBLEMS.md](PROBLEMS.md).
- **Структура папок** (PR #4): `Library`, `Pipeline` (Recognition, Assembly, Study), `UI` по экранам. Версии 0.2.4–0.2.5.
- **«Дополнить»** (PR #9, 0.3.0–0.3.1). Отдельный проход поверх готового конспекта. Текст автора не меняется
  (проверяется кодом), добавленное проверяется вторым вызовом модели. Графики считаются в приложении по формулам,
  схемы SVG проходят белый список, сети нет.

## День 3 — 16 октября: распознавание плотного почерка и доводка

- **PDF сразу в `~/Documents/Конспекты`** с именем `Тема — Предмет — дата.pdf` (0.3.2).
- **Вставка для предмета «Дискретная математика».**
- **Догадки модели** (0.4.0). Правило «никогда не угадывай» смягчено: слово, которое восстанавливается по смыслу, пишется
  `[?слово]` и подчёркивается точками, остальное по-прежнему `[неразборчиво]`.
- **Режим «Подробно»** (0.4.0). Страница читается шестью перекрывающимися фрагментами (сетка 3×2). Замер на странице
  с мелким кеглем: обычный режим — 58 строк из 100 дословно, сетка — 100. Первая версия на полосах была хуже, поэтому перешли на сетку.
- **Версия 0.4.1** (PR #11). Новые возможности приведены к дизайн-системе: переключатели как в тулбаре, компактный индикатор
  работы, полная «Самопроверка», отступы. 17 октября добавлено исправление зависания при запуске (файлы лекции
  в iCloud читались на главном потоке).

## Принятые решения и почему

| Решение | Причина |
|---|---|
| Нет своих API-ключей, вызывается CLI | Работает по подписке, приложение не хранит учётных данных |
| Claude Code основной, Gemini отвергнут | Подписки Google AI Pro больше не обслуживаются (см. выше) |
| Данные — обычные файлы, без базы | Читаются без приложения, живут в iCloud, легко чинятся руками |
| Песочница выключена | Приложение запускает внешние CLI |
| Подпись Personal Team | Стабильная подпись: разрешения macOS не слетают при пересборке |
| Минимум macOS 26 | Liquid Glass и новые стили SwiftUI без веток доступности |
| Сторонний код только как JS-ассеты с зафиксированными версиями | Меньше поверхности атаки, всё работает офлайн |
| Текст автора при «Дополнить» неприкосновенен | Модель только добавляет помеченные блоки, код сверяет результат |
