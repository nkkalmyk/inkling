# Inkling: установка

Инструкция для человека. Если вы ИИ-агент, читайте [`AGENTS.md`](../AGENTS.md): там те же шаги в виде проверяемого сценария.

## Что нужно

- Mac на Apple Silicon, macOS 26 или новее.
- Один ИИ-движок с выполненным входом (своих ключей API у Inkling нет):
  - **Claude Code** по подписке Claude Pro (основной): `claude`, затем вход через подписку;
  - или **Codex** по подписке ChatGPT (не проверен вживую, см. ниже);
  - или только локальная **Ollama** (медленнее и хуже на плотном почерке, см. ниже).
- Для сборки из исходников ещё Xcode (из App Store) и XcodeGen: `brew install xcodegen`.

## Способ 1. Готовая сборка (проще всего)

1. Откройте [Releases](https://github.com/nkkalmyk/inkling/releases) и скачайте `Inkling-<версия>.zip` последнего релиза.
   Репозиторий приватный: войдите в GitHub под аккаунтом с доступом.
2. Распакуйте архив, перетащите `Inkling.app` в «Программы».
3. Первый запуск: macOS заблокирует приложение, потому что оно не нотаризовано Apple (нотаризация платная, 99 $/год). Это ожидаемо, а не поломка.
   Откройте `Inkling.app` двойным щелчком, закройте окно предупреждения, затем «Системные настройки» → «Конфиденциальность и безопасность» →
   внизу «Inkling заблокирован» → «Всё равно открыть» → подтвердите паролем или Touch ID. Делается один раз. Подробнее — «Если ругается Gatekeeper» ниже.
4. Проверьте контрольную сумму (по желанию): `shasum -a 256 Inkling-<версия>.zip` должна совпасть с суммой в описании релиза.
5. Настройки (⌘,) → «Движок» → «Проверить подключение»: должно показать путь к движку, версию и «Работает».

## Способ 2. Сборка из исходников

```
gh repo clone nkkalmyk/inkling && cd inkling
xcodegen generate
xcodebuild -scheme Inkling -configuration Release -destination 'platform=macOS' -derivedDataPath build/DerivedData build
```

Готовое приложение: `build/DerivedData/Build/Products/Release/Inkling.app`.

Тесты: `xcodebuild -scheme Inkling -destination 'platform=macOS' test` (живые вызовы Claude по умолчанию выключены, см. `CLAUDE.md`).

### Установка собранного приложения

```
ditto build/DerivedData/Build/Products/Release/Inkling.app /Applications/Inkling.app
open /Applications/Inkling.app
```

По умолчанию сборка подписывается ad-hoc (без личного сертификата): она запускается, но разрешения macOS («Документы», Камера непрерывности) могут спрашиваться заново после каждой пересборки. Чтобы они сохранялись, подпишите своим бесплатным Apple ID (Personal Team):

```
cp Config/Signing.example.xcconfig Config/Signing.xcconfig   # файл вне git
# впишите свой DEVELOPMENT_TEAM (Xcode → Settings → Accounts) и пересоберите
```

При первой сборке macOS может спросить пароль связки ключей для `codesign` — введите пароль учётной записи Mac и нажмите «Разрешить всегда».

## Если ругается Gatekeeper

Релизная сборка подписана ad-hoc и не нотаризована, поэтому macOS блокирует первый запуск скачанного приложения (на собранном у вас самих блокировки нет).
В macOS 15 и новее старый способ «правый щелчок → Открыть» **больше не обходит** блокировку. Выберите один из двух способов (формулировки в окнах macOS могут немного отличаться):

**Способ 1. Через настройки (без Терминала)**
1. Дважды щёлкните `Inkling.app`. Появится окно, что приложение не удалось проверить. Нажмите «Готово» (не «Переместить в Корзину»).
2. «Системные настройки» → «Конфиденциальность и безопасность» → прокрутите вниз до раздела «Безопасность».
3. Рядом с сообщением об Inkling нажмите «Всё равно открыть», подтвердите паролем или Touch ID, затем «Открыть».
Дальше приложение запускается как обычное.

**Способ 2. Через Терминал**
```
xattr -dr com.apple.quarantine /Applications/Inkling.app
```
Затем откройте приложение как обычно.

Скачивайте только с [страницы релизов](https://github.com/nkkalmyk/inkling/releases) и сверяйте SHA-256 из описания релиза: `shasum -a 256 Inkling-<версия>.zip`.

## Первый запуск

- Данные лежат в `~/Documents/Inkling/` (меняется в настройках, ⌘,). Там же папка `_prompts` с промптами.
- В настройках → «Движок» → «Проверить подключение»: должно показать путь к `claude`, версию и «Работает».
- Если Claude Code установлен в нестандартное место, укажите путь к `claude` вручную там же.

## Запасной движок: Ollama (необязательно)

Локальная модель подменяет Claude, когда закончился лимит подписки, или работает вместо него, если выбрать «Только локальная» в меню «Модель» на панели лекции. Она медленнее (30–70 с на страницу против нескольких секунд) и чаще ошибается на плотном почерке: всё, что она сделала, помечено «проверьте». Подробности — `docs/local-models.md`.

```
brew install ollama
ollama serve &                 # только на время установки модели; дальше сервер запускает Inkling
ollama pull qwen3.5:9b         # ~7,6 ГБ
ollama create inkling-ocr -f docs/ollama/inkling-ocr.Modelfile
kill %1
```

Затем в настройках → «Движок»: «Запасной движок» — «Ollama (локально)», модель `inkling-ocr`, «Проверить подключение». Сервер Ollama приложение запускает само, когда он нужен, и закрывает при выходе (если запускало само). Автозапуск через `brew services` не нужен.

## Codex вместо Claude (необязательно, не проверен вживую)

Если подписка не Claude, а ChatGPT: `brew install codex`, затем один раз в Терминале `codex login` (вход через ChatGPT). В настройках приложения, вкладка «Движок», выберите Codex основным или запасным движком, нажмите «Проверить подключение». Ключи API приложению не нужны и в процесс не передаются. Движок написан по документации OpenAI и ни разу не запускался с живой подпиской: если что-то не работает, раскройте «Подробности» в проверке подключения и откройте issue с этим текстом.

## Учебники для учебного конспекта (необязательно)

«Учебный конспект» работает и без них. Если положить в приложение свои учебники, модель получает выдержки по теме лекции и добавляет «Источники»:

1. Настройки → «Учебники». Если в `~/Library/Application Support/Inkling/Literature/` уже есть индекс, коллекции подхватятся сами; иначе создайте коллекцию (например, «Математика», «Химия») и нажмите «Добавить книги…», выбрав PDF.
2. В блоке «Предметы» привяжите каждый предмет к коллекции.
3. Индексация идёт в фоне. Сканы без текстового слоя распознаются на устройстве (около 6 страниц в секунду на M-серии, книга на 400 страниц — около минуты; процессор заметно нагружается). Прогресс сохраняется: после выхода из приложения индексация продолжится с того же места, неизменённые книги пропускаются.
4. Включайте в коллекции только учебники и задачники: конспекты, билеты и коллоквиумы ухудшают выдержки.

Формулы со сканов распознаются плохо (греческие буквы и индексы искажаются): модель берёт из выдержек слова и определения, а формулы пишет сама. Индекс можно удалить кнопкой «Очистить индекс»; сами книги приложение не меняет и не копирует.
