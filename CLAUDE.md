# Inkling

Нативное macOS-приложение (Swift 6 + SwiftUI, XcodeGen): фото рукописных конспектов → конспект с формулами → самопроверка.

**Главная инструкция для агентов — [`AGENTS.md`](AGENTS.md)**: архитектура, проверенные команды сборки и тестов, конвенции, что нельзя трогать, правила репозитория, установка и релиз. Читай её первой; здесь только то, что важно именно для Claude Code.

- Полное ТЗ — `SPEC.md`; раздел 13 главнее остальных, решения оттуда не пересматривай без вопроса.
- Быстрая проверка перед любым коммитом: `xcodegen generate && xcodebuild -scheme Inkling -destination 'platform=macOS' build test`.
- Живые тесты с настоящими `claude`, Codex и Ollama тратят лимит и память: без просьбы не запускай.
- Не коммить личное: `Config/Signing.xcconfig`, `TestData/real/`, содержимое `~/Documents/Inkling/`.
- Интерфейс и сообщения об ошибках на русском, идентификаторы в коде на английском.
