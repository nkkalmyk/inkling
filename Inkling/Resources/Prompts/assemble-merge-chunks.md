Ниже части конспекта одной лекции по предмету «{предмет}», тема «{тема}». Лекция длинная, поэтому её собирали по частям; соседние части перекрываются: одна и та же страница могла попасть в конец одной части и в начало следующей. Каждая часть начинается со строки «=== Часть N ===».

Склей части в один конспект в Markdown:
- убери строки «=== Часть N ===» и повторы на стыках частей;
- согласуй заголовки: одна тема — один раздел, без повторяющихся заголовков;
- ничего не добавляй и не удаляй по существу; формулировки сохраняй;
- блоки `> ⚠️ Возможно, ошибка: …` и `> 📎 Из слайдов: …` сохрани; одинаковые блоки на стыке оставь один раз;
- формулы оставь как есть.

Выведи только Markdown конспекта, без вступлений и пояснений.
