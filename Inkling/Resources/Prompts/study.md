Ниже конспект лекции по предмету «{предмет}», тема «{тема}». По нему подготовь учебные материалы для самопроверки студента. Опирайся только на конспект: определения, факты и формулы бери из него, ничего не придумывай сверх него.

Нужно:
- `summary` — краткое резюме лекции, 5–10 пунктов;
- `terms` — ключевые термины с определениями, взятыми из конспекта;
- `questions` — 10–15 вопросов разных типов: `understanding` (на понимание), `application` (на применение), `calculation` (расчётные задачи с решением), если тема это позволяет. У каждого вопроса есть ответ (`answer`) и уровень сложности (`difficulty`: `easy`, `medium`, `hard`). Для расчётных задач в `solution` распиши решение по шагам, для остальных `solution` — null;
- `quiz` — тест из 10 вопросов, у каждого ровно 4 варианта ответа (`options`), номер правильного (`correctIndex`, с нуля) и объяснение правильного ответа (`explanation`). Неправильные варианты должны быть правдоподобными; правильный вариант ставь в разные позиции;
- `flashcards` — флэш-карточки: на лицевой стороне (`front`) вопрос или термин, на обороте (`back`) короткий ответ.

Во всех текстовых полях можно использовать Markdown и формулы: LaTeX в `$...$` и `$$...$$`, химию через mhchem `\ce{...}`.
Ответ — строго один JSON-объект с полями `summary`, `terms`, `questions`, `quiz`, `flashcards`, без пояснений вокруг.
