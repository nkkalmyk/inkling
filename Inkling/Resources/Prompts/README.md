# Промпты Inkling

Файлы в этой папке можно править: приложение читает их перед каждым запросом.
«Сбросить к умолчанию» в настройках возвращает исходные тексты, а ваши версии сохраняет в `_старые/`.

- `recognize.md` — распознавание страницы рукописи.
- `recognize-detailed.md` — режим «Подробно»: страница одним запросом по нескольким перекрывающимся фрагментам.
- `recognize-slide.md` — распознавание слайда-картинки.
- `assemble-study.md` — «Учебный конспект»: модель видит фото страниц и текст слайдов и свободно строит конспект (сборка по умолчанию).
- `assemble-study-merge.md` — склейка частей длинной лекции для «Учебного конспекта»: ничего не сокращает.
- `assemble.md` — сборка конспекта только из рукописи.
- `assemble-with-slides.md` — сборка из рукописи со сверкой по слайдам.
- `assemble-slides-only.md` — конспект только по слайдам.
- `assemble-merge-chunks.md` — склейка частей длинной лекции.
- `enrich.md` — «Дополнить»: резюме, пояснения, примеры, схемы поверх готового конспекта.
- `enrich-verify.md` — проверка добавленных блоков вторым проходом.
- `study.md` — учебные материалы: резюме, термины, вопросы, тест, карточки.
- `subjects/<Предмет> — учебный.md` — вставка «Учебного конспекта» для предмета: что должно войти в конспект, какие обозначения и какие типовые задачи разбирать (есть для химии, математического анализа, высшей алгебры и дискретной математики). Для нового предмета создайте такой файл сами.
- `subjects/<Предмет>.md` — вставка для предмета; имя файла должно совпадать с названием предмета (есть для химии, математического анализа, высшей алгебры и дискретной математики).
  Образцы лежат в `subjects/_образцы/`.

Подстановки: `{предмет}`, `{тема}`, `{вставка_предмета}`, `{страницы}`, `{слайды}`, `{конспект}`.
